YC-STOCK-APP

個人台股研究、資料整理與 Google Drive 備份工具。

隱私權政策 · 使用說明 · 聯絡

應用程式用途

YC-STOCK-APP 協助使用者追蹤台股公開行情、財務資料、觀察名單與個人研究紀錄。背景更新透過 GitHub Actions 執行，Google Drive 整合用於讀取指定資料夾中的支援格式資料，以及新增資料庫備份。

本工具供擁有者個人使用，不提供自動下單或證券交易服務。本頁只提供應用程式資訊，不顯示投資紀錄或私有程式碼。

隱私權政策

生效日期：2026-10-04。適用於 YC-STOCK-APP 的 Google Drive 背景同步。

存取哪些資料

經使用者 OAuth 同意後，程式讀取設定資料夾與檔案的識別碼、名稱、類型、大小、修改時間，以及符合匯入命名規則的 CSV 或 Excel 內容。備份可能包含觀察名單、公開市場資料、估值假設、個人交易與研究紀錄、匯入紀錄及執行狀態。

如何使用與儲存

讀取資料用於使用者要求的匯入與研究功能，資料儲存在應用程式所設定的持久化資料庫。背景執行環境暫時處理匯入內容與備份檔，備份新增至指定的 Google Drive 資料夾。程式不自動刪除 Google Drive 原檔，也不覆寫既有備份。

OAuth 憑證由部署環境的秘密設定提供，例如 GitHub Actions Secrets；不得存入公開程式碼、公開網站或一般執行紀錄。程式以 HTTPS 存取 Google API。程式會以資料夾識別碼限制操作，但此程式限制不代表 OAuth 權限本身只限於單一資料夾；實際授權範圍以 Google 同意畫面為準。

服務供應商與資料分享

Google 提供授權及 Drive 儲存；GitHub Actions 提供背景運算；應用程式設定的資料庫服務商處理持久化儲存。資料僅為上述功能而傳送至相關服務，不出售、不用於廣告、不用於訓練通用 AI 模型，不主動公開使用者資料。Google API 資料的使用遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保留與撤銷

資料庫紀錄與 Drive 備份保留至擁有者自行移除，沒有自動清理期限。使用者可在 Google 帳戶連結管理撤銷存取權，並停用背景工作及移除部署環境的 OAuth 秘密設定。撤銷授權會停止後續授權存取，但不會自動刪除既有匯入資料或備份。需要刪除時，請由擁有者分別處理資料庫、Drive 與執行紀錄。

使用說明

本工具用於個人研究與資料整理。公開來源可能延遲、缺漏或變更，使用者應自行核對重要資料。研究結果不是投資建議，不保證報酬。使用者須確保有權存取所選資料，並自行管理帳號、授權、備份及資料保留。
